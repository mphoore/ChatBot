MainWindow.xaml.cs- When the application boots, it sets up its initial state by instantiating memory objects, including generic List<string> and legacy ArrayList collections to store bot answers and words to ignore, an instance of a custom user_name class, and primitive variables like a string for the active user's name and an int counter to track conversation turns. Screen navigation is handled by a UI event handler method that runs on a button click, toggling the Visibility property of structural grid containers between hidden and visible states on a single window. When a user submits text, an input sanitization method uses a loop to evaluate individual characters, passing them to a StringBuilder object to discard symbols and prevent punctuation from breaking the search logic.
The program then passes this sanitized text to the ai_check method, which uses string manipulation methods like .ToLower() and .Split() to break the sentence into an array of isolated string elements (tokens). If a conditional if statement detects the token "interested", the logic switches to file management: it calls file I/O methods like File.Exists(), File.ReadAllLines(), and File.WriteAllLines() to sequentially read a local text file, check line string values for a matching username, update the data while filtering out duplicates using a HashSet, and overwrite the file.
If it is a standard chat message, the engine runs nested foreach loops combined with conditional if statements to cross-reference every token the user typed against the pre-loaded bot answers collection using the .Contains() method. If matches are found, they are grouped into a temporary list, and an instance of the Random class invokes its .Next() method to pull an answer from a random index integer boundary; if the list is empty, a fallback array of hardcoded string messages provides an answer instead. Finally, the error_method UI layout method handles visual output by programmatically instantiating WPF control objects (Border, TextBlock, and Run), configuring their layout attributes (like Margin, Background, CornerRadius, and FontWeight), assigning the text block as a child node of the border, appending the completed layout control to the Items property of the chat display box, and calling the .ScrollIntoView() UI method to force the screen downward.


Voice_greeting.cs- he voice_greeting class functions as a public, single-purpose utility module containing a public void instance method named greet(), which executes audio playback actions without returning any data value types to the caller. Inside this method, the program avoids hardcoded errors by accessing the AppDomain.CurrentDomain.BaseDirectory system property to locate the application's runtime executable path, then invokes the string manipulation .Replace() method using verbatim literals (@) to safely handle folder backslashes, swapping the local \bin\Debug\ development directory for a direct path to the \greet.wav asset. This modified path is stored inside a standard string primitive variable named auto_path and passed as a constructor argument to instantiate a new SoundPlayer class object using the new keyword, which assigns the player to the greetMe object reference variable. Finally, the code calls the player's native .Play() method, commanding the operating system to stream the audio file asynchronously on a background thread to prevent the main user interface window from freezing during playback.




user_name.cs- The user_name class functions as an identity and presentation management module that uses file persistence and dynamic UI components to track profile states. At its core, the public submit_name method accepts a TextBox and a ListView control reference as parameters, ultimately executing a return statement to pass a string primitive variable of the validated username back to the main user interface. Inside this pipeline, the program calls the static file I/O methods File.Exists() and File.AppendAllText() to evaluate if the local flat file user_names.txt exists, automatically writing a tracking header if it needs to initialize the storage stream. To search for existing profiles, the private check_name method invokes File.ReadAllLines() to populate a one-dimensional (1D) array named names, loading every saved user entry into sequential memory layout indexes.To parse these data slots, a foreach loop iterates through the string entries of the array, executing a conditional if statement that applies the .ToLower() string modification method to normalize case variations and eliminate capitalization discrepancies. If a match is found, a Boolean data flag flips to true, prompting the outer logic to branch through an if-else statement to either write a fresh identity string to disk or toggle between standard or returning welcome messages. Finally, the private error_method handles visual tree presentation by using the new keyword to programmatically instantiate framework control objects (Border, TextBlock, and Run text fragments). It configures structural layout attributes such as Margin, Padding, and CornerRadius, implements a conditional ternary operator to dynamically swap a SolidColorBrush between theme colors based on the sender's name, binds the elements together through the .Inlines.Add() composition method, and pushes the completed control block to the screen by invoking the .Items.Add() UI method.





respond.cs- The respond class acts as the data initialization engine for the chatbot, using a public instance constructor that accepts two legacy ArrayList collections as parameters (reply and ignore) and runs automatically when instantiated via the new keyword. Because C# passes objects by reference, the constructor directly populates the original data vectors living inside the main application by invoking two encapsulated, private helper methods named words() and answers(). Inside these sub-routines, the code utilizes the .Add() collection method to sequentially append string primitive entries to the end of the lists. The words() method builds a filtering array of common "stop words" like conjunctions and prepositions to help the bot skip conversational noise, while the answers() method populates a knowledge database where each data item is a string variable structured with a specific category keyword prefix (such as "vpn", "phishing", or "frustrated") followed by a descriptive cybersecurity response or sentiment-matching answer body.
